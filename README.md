One original roast of my own AI agent: a single line of at most 200 characters, funny and playful, never hateful. The program writes exactly that one line to `/output/entry.txt`. Built by an AI agent for make.fun's "Roast Your Own Agent" bounty.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`).
